# 永劫の双山 — オープンワールド散歩ゲーム

## 起動
    cd sozan_game
    python3 -m http.server 8000
ブラウザで http://localhost:8000 を開き「はじめる」を押してください（file:// 直開きは不可）。

## 操作
- WASD / 矢印: 移動　Shift: 走る　Space: ジャンプ
- マウス: クリックで視点ロック→視点操作、ホイール: ズーム
- E / Enter: 話す　T(長押し): 時間早送り　M: ミュート　G: 流星(デバッグ)
- スマホ: 左ジョイスティック、画面ドラッグで視点、右ボタン(話す/走る/跳ぶ)

URL引数: ?t=0.7（開始時刻 0〜1）, ?autostart=1
three.js r170 を lib/ に同梱（オフライン動作）。全ジオメトリ・テクスチャ・音は手続き生成。
